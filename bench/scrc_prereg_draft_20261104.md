## 論文との違い（はっきり書く）
- 論文（arXiv 2512.12844、4.5 節・式 17〜23）の SCRC-I は **2 段**：①選択の境界、②選択されたデータ上の予測集合のリスク制御。
- ここでやるのは **SCRC-I を参考にした 1 パラメータの選択的リスク制御**だけ。予測集合は作らない（ジツリスは 1 つのラベルか unknown を返す）。論文の完全な再現ではない。
- 論文は画像・標本単位。ここは表の列で、損失は「重大」（日付・金額・数量・率・番号の取り違え）。単位は表（下の「単位」）。

## 変えること（1 つだけ）
- `numeric_top2_too_close`（guard.py の数の種類どうしの 1 位と 2 位の差、今は 0.25）の τ だけ。ほかの見張りの規則・モデル（土台 L＋直し G）は固定。
- 候補：τ ∈ {0.00, 0.01, …, 0.50}（K = 51）。**E4・較正の陣のラベルを見る前に固定**。

## 定義
- 受け入れ：`S_τ = 1[数の種類どうしの差 ≥ τ]`（ほかの見張りで unknown になった列は S_τ = 0）
- `q(τ) = E[S_τ]`、`N(τ) = E[S_τ × 重大]`、条件付きの重大リスク `R(τ) = N(τ) / q(τ)`
- 棄却した列を損失 0 として N に数えるだけでは R を保証できないので、q の下限と N の上限を**別々に**作る。

## 境界（較正の陣について確率 1 − δ）
- δ = δ_q + δ_N、δ_q = δ_N = δ/2。
- `q_LCB(τ) = q̂(τ) − √(ln(1/δ_q) / (2n))`：S_τ は τ について単調なので片側 DKW（Massart）で全候補に同時に有効。
- `N_UCB(τ)`：S_τ×重大 は 0/1 なので、**Clopper–Pearson の片側上限を水準 δ_N/K で**（Bonferroni で全候補に同時に有効）。Hoeffding（`N̂ + √(ln(K/δ_N)/(2n))`）も有効だが 0/1 で平均が小さい損失には緩すぎて実行できない（下の見積り）。**本命は Clopper–Pearson。** この置き換えは論文からの変更点として書いておく。
- 選び方：`N_UCB(τ) ≤ α · q_LCB(τ)` を満たす候補のうち受け入れがいちばん多い τ（同じなら小さい τ）。**どれも満たさなければ「候補なし・変更なし」**（0.25 に戻すのは保証されないので、結果として「SCRC で選んだ」とは書かない）。
- 主張できること：較正の陣と同じ分布から独立に引いた単位について、確率 1 − δ で R(τ\*) ≤ α。**重大 0 の保証ではない。** 公開元が違う陣（E4 を含む）では交換可能性が自明でないので、新しい公開元への保証と同じには扱わない。
- 計算：`scrc_feasibility.py`（`passes`・`select`）、試験 `tests/test_scrc_feasibility.py`。

## α と δ（E4 の結果を見る前に固定する。別の値）
- α：受け入れた列の重大リスクの上限の目標。δ：保証が成り立たない確率。
- 案：**δ = 0.05**。α は下の見積りと、集められる較正の単位数で決める（0.005 は単位がおよそ 1,750 必要。0.01 なら 約 900）。
- E4 で観測した重大の数（0 件など）は、保証とは別の実測として書く。
