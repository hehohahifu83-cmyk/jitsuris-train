## 変えること（1 つだけ）
- **数の種類どうしの差のしきい値 τ（今は 0.25、`numeric_top2_too_close`）を、較正の陣で決めた τ\* に置き換える。** ほかの見張りの規則は今のまま。
- τ\* の決め方（SCRC-I、固定の境界）：
  - 損失：受け入れた列が**重大**（日付・金額・数量・率・番号の取り違え）なら 1、ほかは 0。
  - 較正の陣で、τ を 0.00〜0.50 の 0.01 刻みで動かし、受け入れた列 n(τ) と重大の数 k(τ) から、上限 U(τ) = (k(τ) + 1) / (n(τ) + 1) を出す。
  - U(τ) ≤ α を満たす τ のうち**いちばん小さい τ**（いちばん多く受け入れる）を τ\* にする。α = 0.005（重大 0.5% 以下）。満たす τ が無ければ今の 0.25 のまま（この回は「要因なし」）。
- 0 の段（読むだけ、採否に使わない）：使い済みの陣で、raw の正解を unknown にした出力の理由（reason）の内訳を数える。`numeric_top2_too_close` が少なければ、変える規則を日付の値のしきい値（0.5）に替える（どちらにするかは、固定の前にこの数を見て決め、ここに書く）。
