# W4 見出しを隠して学習する（2026-10-21 22:12 Claude 判定：**不合格・候補にしない**）

計画：`specs/IMPROVEMENT_PLAN.md` 9.2 W4（S13）の前半。要因は 1 つ：`FT_HMASK=0.15`（学習の行の 15% の見出しを「（なし）」に替える。`encoder_context.mask_headers`。どの行かは行の中身の SHA-256 で決まり、種子に依らない）。評価の文は変えない。種子の重みの平均（W4 の後半）は別の要因として後で試す。

根拠：既知の見出しは 98% 当たり、未知の見出しで落ちる（固定試験の診断・主セット #1）。見出しが無い行でも値と同じ表の列から当てる練習をさせ、見出しへの頼りすぎを減らす。

## 判定の規則（事前に固定。W3a と同じ形）
- 主：検証の未知見出し（255 列）の OK 率の 3 種子平均で、W4 − 基準線 ≥ **+1.0 ポイント**、かつ全 889 列の重大の 3 種子平均が基準線**以下**なら、封印セット #2 に出す候補。
- 副（判定には使わない）：未知見出し macro-F1、全 889 列の OK 率、既知の見出しの OK 率（下がりすぎないか）。
- +1.0〜1.5 は「種子の幅の中」と書く。
