# 検査役 v2（値・表の中の関係を見る別の観点の AI ＋ 重大検知役、2026-10-25 Claude。`verifier.py`・`verifier_eval.py`）

オーナー指示：「本体とは別観点から調べるタイプのAIにできるならそれで実行してくれ」「不明なものは再検査するルールは有効なままにしておいてくれ」「どんな方法でも良いが検査係の強化を続けてくれ」「途中でチャットGPTの案も聞いていいぞ」。v1 は `bench/verifier_v1.md`。

## 仕組み
- 順番：見張り → **recheck v1（言い切りの検査と不明の再検査。そのまま有効）** → 検査役 v2 と重大検知役（どちらかが下げれば不明）→ 不明の列に候補を添える
- **検査役 v2**：列名を読まない。値の並び（v1）に、同じ表のほかの列・行の並び（表の中の位置・すぐ隣の 2〜8 列の和と等しいか＝合計の列・行の番号との相関・表の行数との比・ほかの数の列との相関）を足した木のモデル
- **重大検知役**（ChatGPT の案 4）：数字の種類と言い切った列だけを見て「重大な誤りか」を当てる二値の木のモデル。入力は値・表の特徴、検査役の確率、本体の上位 3 つ、recheck の理由。**本体の確率を使うので、本体の版を変えたらその版の予測で作り直す**
- 決め方：tau（0.01, 0.02, 0.03, 0.05, 0.08, 0.1, 0.15, 0.2, 0.25, 0.3, 0.4, 0.5）と th（None, 0.3, 0.4, 0.5, 0.6, 0.7, 0.8, 0.9）の組を、ほかの陣で「下げた列のうち本体が本当に間違っていた割合」が 50% 以上の組のうち重大が最も少ない組にした（陣を 1 つずつ外して決め、外した陣で測った）。割合 50% の線は v1 で事前に決めたもの。重大が最も少ない組を選ぶのは v2 で足した
- 検査役と重大検知役も陣を 1 つずつ外して学んだ。重大検知役の入力の検査役の確率は、陣を外して出した確率（学習側の陣の確率は外した陣も見たモデルのもの。わずかな漏れ）

## 書き出し
- 全部の陣で学び直したモデル：`models/verifier_v2.json`（tau＝0.05、th＝0.7、rho＝0.8。書き出した JSON と sklearn の確率の最大の差 2.5e-05）。`verifier.Verifier.load()` と `verifier.apply_after_recheck(..., rows=, table=)` で使う
