# ジツリス 学習用（公開）

表の列の種類（日付・金額・取引先など）を判定する小型AI「ジツリス」の研究用の学習手順です。

- 中身：学習・試験のコード、公開データ（英・アイルランド・カナダ・日本の公的なオープンデータ）から作ったラベル。個人の連絡先の列は取っていません。
- 入れていないもの：未見の試験セット、お客さまのデータ、サイトのコード、鍵。
- 学習は Kaggle の無料 GPU で行います。`kaggle/kaggle.request` を書き換えて push すると、GitHub Actions が Kaggle に依頼し、結果を `FINETUNE_RESULTS.md` に持ち帰ります。
- 学習済みモデル（multilingual-e5、MIT ライセンス）は Hugging Face から取得します。
