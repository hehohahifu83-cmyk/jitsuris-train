## 決まり（9.5「呼び方の決まり」）
- 道具はプログラムが**決まった順番で毎回全部**呼ぶ。ジツリス（モデル）が道具を選ぶ形（エージェント）にはしない（9.3 の 5）。
- AI は使わない。ブラウザの中だけで動き、**外と通信しない**（G6）。
- **Python と JS で同じ結果**にする。`python jtools/make_fixtures.py` で正解を作り、`node --test jtools/parity.test.mjs` で確かめる（Actions `jtools-tests.yml`）。
- 割合は整数の数で返す（Python の round と JS の Math.round の違いを避ける）。

### 本物の表で動かした結果（教材庫 1,448 表、`table_arith`）
- 和 56 組・同じ値 78 組・比率 19 組・片側だけ 28 組・積 3 組（世帯数 × 1 世帯当たり人口 ＝ 総数 など）。5 秒ほど。
- 法人番号は「法人番号」の列だけに、団体コードは「区コード」「全国地方公共団体コード」「市区町村コード」の列だけに当たった。
- 直した偶然の当たり：5 桁の数を ZIP と読む（外した）、同じ値の並ぶ列で EAN の検査数字が偶然合う（違う値で数えるようにした）、
  小さな小数で税の額が合う（10 以上の値だけ数える）、〇（有の印）を漢数字の 0 と読む（〇 だけは数にしない）。

### 知っている限界
- 行のそろった値は 1 表あたり最大 20 行の抜き取り。合計の行（表の最後の行）は見つけられない。
- 「1.5万」は 1.5（倍率 1 万）、「3万5千」は 35000 と返す（漢数字だけの数は倍率を中に含む）。
- 8 桁の 20240401、Excel の日付の番号、UNIX 時刻は「数」として返す。日付かどうかは列名と合わせて呼ぶ側が決める（直し H2 と同じ考え）。

## ジツリスへのつなぎ方（まだつないでいない）
道具の結果をどこに使うかは、1 回に 1 要因の決まりで事前記録してから測る。候補は 2 つ：
1. **見張り・recheck の材料**（学び直し不要。直し G・H と同じ形で、今の誤りの多い所に当てる）
2. **本体の入力の文に足す**（`run_tools` の text。学び直しが要る）
