# 独立評価セット候補の発見

この段階では、公開カタログから候補表を見つけ、出典・題名・ライセンス情報・安全な見出し名などのメタデータだけを記録します。先頭5行の値は個人情報らしい文字列を検査するためにメモリ上で読みますが、候補ファイルやログには保存しません。ラベルと生CSVも保存しません。

候補一覧は `independent_eval/results/discovery/` に生成されます。公開前提のメタデータです。実データを使う独立評価セットは、候補ごとの利用条件・安全性・学習データとの重複を確認してから、別工程で抽出してください。5件の値やラベルはこの公開リポジトリやその成果物へ置かないでください。

評価入力は `evaluate_independent.py` の schema_version 1 に合わせます。ラベルファイルは入力セットと分離します。候補の発見だけでは、主セットの固定やモデル評価は行いません。
