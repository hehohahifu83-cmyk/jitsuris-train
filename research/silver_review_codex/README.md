## 不一致の理由（値の転記なし）

- s021・g0452：org → unknown。施設名と入場券の説明が混在し、表の役割も分からない。B10で一律orgとできない。
- s027・g0074：org → unknown。見出し・題名・文脈なしの単一値では組織と題名を区別できない。
- s045・g0322：amount → unknown。見出し・通貨・題名のない数だけでは金額を確定できない。
- s053・g0023：quantity → unknown。同じく数だけでは数量・金額・コード等を区別できない。
- s065・g0236：rate → unknown。Gini係数の尺度が混在し、率か指数かの境目。LABEL_GUIDEは指数をunknownにしやすいとしているため裁定を依頼する。
- s071・g0178：address → category。国名でなく国旗を表すUnicode文字の列。住所に読み替える妥当性は裁定が必要。
- s075・g0700：date → id。日付の綴りの形でも、列名は外部サービスの識別子。値の形より列の意味を優先する。

s009（org）はホテルの名前として判断したが、機関か場所かを確定する表の属性がない点は留保する。独立判定確定後の恣意的な変更は行わない。

## 次の学習の条件への意見

1. 数の種類を外す方針は妥当。ただし本検査は、外せば効果が出ることや残る銀が安全であることを示さない。org等の文脈不足も対象にし、上記の規則をClaudeが裁定してから使う。
2. rhoのamount復帰に通貨・金額の根拠を求める案は妥当。既存のamount_cue_vetoとの関係を明記する。銀データの変更とrhoの変更を同時に比べるだけでは原因を分離できないので、銀あり/なし×rho制限あり/なしを同じ入力・版・種子で比較する案を推奨する。
3. 「銀の金額ラベルが小数＝金額を覚えさせた」は因果仮説である。保存予測の経路再現とラベル不一致だけでは、学習量・種子・分布差の影響を排除できない。数の種類を入れない銀で数の不明が改善するとの期待は置かず、まず重大を増やさないことと非数値の効き目を別に測る。GitTables 1M は今回検査した銀と異なるため、この一致率を移して使わない。

学習依頼・事前記録の固定・採否裁定は行っていない。
