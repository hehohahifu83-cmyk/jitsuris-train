# Codex 独立回答の注記

- g0002/g0003 の「11年」「9年」は産業分類別の数値だが、数量・金額の単位をシート/抽出済み文脈で確定できず unknown（年見出しだから date とはしない）。元表 `https://www.pref.ehime.jp//opendata-catalog/fs/1/1/2/8/1/_/shougyou-d01_5.xlsx`。
- g0004 増減率は rate。シート例に単位記号 (%) が混ざるので元表の見出し/単位行の除去を裁定前に確認してください。
- g0008 ICD-10 は疾病分類のコードなので B3 の種類コードとして category（行識別用の id 列は別にある）。g0007 部位も疾病の選択肢として category。迷う境界として裁定に引き継ぐ。
- g0019 管理グループは県名も混ざるが、抽出済みの値は大半が県の部署・課なので account。元表はカタログ一覧。
- がん罹患は集計表であり個人別の医療記録ではない。個人別の記録の表は今回見たシート・対応する抽出済み値には認めなかった。モデル予測・他教師回答・裁定は未閲覧。
