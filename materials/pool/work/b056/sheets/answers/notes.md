- このシートの列群は助成制度・対象区分・制度説明、資源許可の年次集計、地図メタデータ、処理実績の集計。個人または1件ごとの記録に該当する表は確認できず、全列Sの指定はない。
- g0012 は「Sub-program title」の値が説明文なので text。
- g0028 は見出しが「Finanical Year」だが例は「Petroleum」「Mineral」の区分値なので category。g0029 の GL・PSL 等も資源許可の区分コードとして category。表題「Total of granted resource authorities by financial year in Queensland」を文脈に、g0030〜g0037 は年ごとの許可総数として quantity。
- g0047 Map Scale は地図縮尺の比率・測定値として other。g0048 と g0050 はURLなので other。g0049・g0051 は MB 表示のファイル容量なので quantity。
- g0052 Download Format は複数の形式情報を含む説明文なので text。g0053 Copyright status は権利状態の区分として category。g0057 Target は割合と期限を記した目標条件の文なので text。
