# Codex 独立回答の注記

- g0062 団体名は自治体名と社会福祉法人名が混在するため unknown。元表 `https://opendata.pref.tokushima.lg.jp/fs/2/7/5/3/7/_/363413_preschool.csv`。抽出済み row_values の全要素を確認したが元ファイル全行の比率までは不明。
- 子育て施設は種別・機関属性を持つ同種機関一覧として org。公共施設・AED・避難場所の名称（役場庁舎を含む）とその読みは B10.3 で address。g0117 は人数に算出根拠が付くため quantity。
- 駐車場情報は有無だけなら category、台数・共有・但し書きが入る説明は text。g0080 も「駐車スペースN台」という文の列として text（数量列への正規化をしていない）。
- 個人別の記録の表は今回見たシート・対応する抽出済み値には認めなかった。モデル予測・他教師回答・裁定は未閲覧。
