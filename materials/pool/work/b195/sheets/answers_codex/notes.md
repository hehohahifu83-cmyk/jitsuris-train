# Codex 独立回答の注記

- 投票所/避難所の名称/読み/英字はaddress。対象となる町会・自治会は避難対象区域を指すのでaddress。
- 学校名/読み/略称は学校種や設置区分等を持つ機関名簿なのでorg。学校種・設置区分はcategory。
- 測地系とそのコード（EPSG）は方式・種類の区分としてcategory（B3）。物や場所の行を指すidentifierはid。
- cityBlockは番地の意味なのでaddress。日付風の値が混ざっていてもdateにはしない。元表の自動型変換の有無は未確認。

- 今回のモデル予測・他教師回答・裁定・先例ラベルは未閲覧。個人別の記録と判断できる表は今回見た範囲では確認しなかった。シートと境界列の抽出済み値を見たもので、元ファイルの全行確認をしたとは扱わない。
