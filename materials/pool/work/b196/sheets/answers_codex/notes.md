# Codex 独立回答の注記

- 観光施設や直売所・山・神社が混ざる場所一覧の名称/読み/通称はB10.3でaddress。説明はtext。
- schoolCode/mainSchoolCodeはid、schoolType/establishmentType/mainOrBranchSchoolはcategory。establishingOrganizationは役所でorg。
- 測地系とそのコードは方式の種類としてcategory（B3）。serviceDayは曜日の区分、startTime/endTimeは時刻でdate。

- 今回のモデル予測・他教師回答・裁定・先例ラベルは未閲覧。個人別の記録と判断できる表は今回見た範囲では確認しなかった。シートと境界列の抽出済み値を見たもので、元ファイルの全行確認をしたとは扱わない。
