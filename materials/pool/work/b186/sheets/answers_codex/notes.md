# Codex 独立回答の注記

- qw（g0028）は献立表の数値だが見出しから役割が確定できず unknown。
- 公共施設・AED・公衆トイレ・避難所・観光地の名称/読みは B10.3 の address。保育所（g0051/g0060）・診療所・介護サービス事業所は機関の属性と表の役割により org。
- g0076「設置位置」は値が課名だけなので account。g0106「外部識別子」は識別方式ISILという区分なので category、その値g0107は id。
- g0102〜g0104は○○を含む雛形の例示値しかなく、実際の施設名として使えないためS。元の名称g0101は実在の施設が並ぶためaddressのまま。雛形値の除去をお願いします。
- 文化財の名称/読みは動産・史跡が混ざるのでunknown。所有者g0085/g0118は自治体・宗教団体・匿名の個人などと区別しきれない値がありunknown。個人名をこの注記へ転記しない。元表の所有者列全体を確認し、個人情報がある場合は表単位の除外・保存値の除去をお願いします（個人名の存在を確認済みとはしていない）。
- g0149「概要」は抽出済みの非空値が指定日なのでdate。g0165料金は料金説明の文なのでtext、口径は測定値other。

- 今回のモデル予測・他教師回答・裁定・先例ラベルは未閲覧。個人別の記録と判断できる表は今回見た範囲では確認しなかった。シートと境界列の抽出済み値を見たもので、元ファイルの全行確認をしたとは扱わない。
