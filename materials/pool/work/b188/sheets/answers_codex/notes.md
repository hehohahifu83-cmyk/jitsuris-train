# Codex 独立回答の注記

- g0001〜g0010は年代と年齢別死亡者数の集計表だが、値に「死亡者数」の小見出しが混ざる崩れた表なので全列S。個人別死亡記録ではない。先例で隠れた同表の列も含め、表単位で除外・再生成をお願いします。
- g0025/g0026は長音の欠け記号だけなのでS。イベントの開始日g0023は時点を表すためdate。
- 診療科目g0041は診療の種類の組合せでcategory。タグg0059、分野g0060/g0061、グループg0063は決まった分類/グループの値としてcategory。駐車場や開館の注意を含む文はtext。
- g0087〜g0095の月別数値はファイル別ダウンロード数の表（元表名opendatadl_2019）なのでquantity。g0106〜g0113は国籍別人口の表なのでquantity。国籍名と国籍コードはガイドの国/国コード規定に従いaddress。
- g0101設置者は法人・自治体の混在で、運営主体としてorg（自治体名だけの列ではない）。
