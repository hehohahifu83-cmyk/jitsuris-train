# 除外・迷いの記録

- g0068〜g0077（RESPID、言語・属性・年齢層・地域・回答欄）は、回答者ごとの調査記録です。個人属性を含む1人ごとの記録表として、全列を S にしました。
- g0063（Separate Interac e-transfer limit）は提示例がすべて `-`、g0067（Recipe_Type）はすべて `NA` で、判断できる値がありません。空欄相当として S にしました。
- 判断の根拠を残す項目：g0079 Fiscal Period は会計期間を示す date、g0082 Branch と g0083 Service は組織内の部門・サービス単位として account、g0085 Value は単位・意味が示されない汎用値なので unknown。
