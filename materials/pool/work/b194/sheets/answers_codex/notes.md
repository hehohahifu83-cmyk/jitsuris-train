# Codex 独立回答の注記

- 子育て機関と学校の名称/読みは、種別/学校コード等の機関属性を持つ名簿なのでorg。建物名等（方書）はaddress。
- g0016団体名は自治体名と病院が混在するのでunknown。非空値の比率だけで実体を変えない。
- startTime/endTime（g0030/g0031）はExcelの1日内時刻の小数で、列名と対応する時刻列の文脈があるのでdate。feeは料金の数値なのでamount。
- 営業許可は事業所の許可番号・許可日等が並ぶ記録で、今回の抽出済み列には申請者の個人名は見えない。元のファイルの全行を見たという意味ではない。個人名を含む列が別途保存されていれば表単位の除外をお願いします。

- 今回のモデル予測・他教師回答・裁定・先例ラベルは未閲覧。個人別の記録と判断できる表は今回見た範囲では確認しなかった。シートと境界列の抽出済み値を見たもので、元ファイルの全行確認をしたとは扱わない。
