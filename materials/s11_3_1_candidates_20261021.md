この一覧は候補発見用です。採用の決定・値の取得・ラベル付けはしていません。取得したのはカタログ情報、CSV/TSV の列スキーマ、行数のみです（CKAN datastore API は limit=0）。表のセル値・先頭行・元 CSV は取得・保存していません。

## 一次調査の範囲

- independent_eval/allocation.json の pool=train にある BODIK 公開元のみ。自治体コードは調査前に割当を確認。
- ライセンスは個別データセットの CKAN license_id / license_url で確認。候補行は CC BY 4.0 のみ。
- 検索語: 契約・調達・入札・落札・随意契約・支出・支払・補助金・交付・助成・委託・予算・決算・歳入・歳出・基金・指定管理・使用料・手数料・公有財産・物品・財政・入札結果・歳計・公債。
- 題名・列名は independent_eval/discover.py と同等の個人・連絡先・自由記述除外を適用し、除外列名は記録しない。
- 同一公開元は最大 3 表。年度だけ異なる表は重ねず、原則として最新の形式または異なる会計表を選択。
- ○ はライセンスと列見出しの一次確認のみ通過。値を見ていないため、採用前に許可済みのプライバシー検査が必要。保留は除外見出しのある列を落とした後でレビューが必要。

## 進捗

- 候補行: 120 表 / 53 公開元（確認済み○ 83表 / 42公開元、保留 37表）。候補件数・公開元数の目安（120表 / 40公開元）は候補行ベースで満たしました。確認済み○候補は83表 / 42公開元で、目安まで37表です。保留45表のスキーマAPIを照会し、24表で列見出し・行数を取得しました。うち8表を○へ更新（予算3、入札結果1、請負契約額集計1、公営駐車場等の使用料・料金表3）。料金表は実収入ではなく料金体系候補です。残る保留37表のうち16表は見出し不十分または対象適合が弱く、21表はCKAN datastore対象外でスキーマAPIから取得できませんでした。
- BODIK の対象語検索で候補として抽出し、表スキーマを確認できたものを収録。e-Gov のデータセット一覧・一部 XLSX の存在は確認できたが、データポータルの詳細ページ/API が HTTP 403 となり、許諾条件・列見出し・行数を取得できないため本表へは算入していない。
- 1 表は数値だけの列スキーマ名が混じり、実見出しと確認できないため候補から除外。数値ラベルは一覧に保存していない。
- e-Gov の一次メタデータ取得経路は HTTP 403 のまま。列見出し確認済みのtrain公開元は42組織。確認済み○候補は83表 / 42公開元で、目安の120表まで37表不足です。
- 調査初期にtrain側のサーバー絞り込み前のBODIK検索結果へ一時的にアクセスした。非trainのカタログメタデータが一時レスポンスに含まれたが、候補一覧へは混入させず、行データ・配布ファイルも取得していない。混在した一時JSONは削除済みで、その後はCKANのtrain組織フィルターをサーバー側で指定して検索した。
