# ジツリスの辞書（専門家の手がかり）（2026-10-25 Claude。オーナー指示「より正確な方を選べ、間違えやすいものには見分け方も教えろ」）

## 方針
- **外部の公式データから作る**（教材庫からは作らない）。理由：公式の一覧は名前の誤りがなく網羅的・評価用の表と独立。教材庫は先生のラベルの誤りが入り、出てきた名前しか持てない
- 教材庫（b001〜b014）は「辞書が当たった列の正解率・外れ方」を測る物差しにだけ使う。封印セット・固定試験は使わない
- 辞書に当たっただけでは種類を決めない。列名・同じ表の列・値の形と合わせて、下の「見分け方」で専門家に渡す
- 取るのは GitHub Actions（この作業環境からは外に出られない）。出典を書けば使える公開のものだけ。取った日・URL・SHA-256 を記録する
- 判定の基準を LABEL_GUIDE に入れるのは、封印セット #3 のラベル付けが終わってから（#3 は v1.9 で事前登録）

## 間違えやすいものの見分け方（案。ChatGPT に確認を頼む）
| 迷う組 | 見分け方 |
|---|---|
| 自治体名：address か org か | 「設置者」「団体名」「事業主体」に自治体名だけ → address（v1.9）。「○○市役所」「○○町教育委員会」 → org。「○○市 財政課」 → account |
| 施設名：org か address か | 学校・公民館・病院・センター・駅など組織として活動 → org。公園・橋・史跡・団地・岬など場所そのもの → address（v1.6）。半々なら unknown |
| Department：org か account か | 独立した役所の名前・略号（DPS・HHS） → org。組織の中の部署・課・会計区分（Finance・General Fund） → account |
| 番号（id）か数量か | チェックデジットで確かめる：法人番号（13 桁）、全国地方公共団体コード（6 桁目）、CNPJ・CPF。合えば id。合わない整数で、合計の列と足し算が合えば数量 |
| 郵便番号：address か id か | 日本の 7 桁（123-4567）、ブラジルの CEP（12345-678）、米国の ZIP → address。形と列名の両方で |
| 電話か番号か | 市外局番の形（03-、0120-、(11) 9xxxx-xxxx、+55） → phone。電話の形でない連番 → id |
| 年：date か数量か | 1900〜2100 の整数で列名が「年」「年度」「year」 → date。列名が「件数」「人数」 → quantity |
| 金額か数量か | 列名・単位に円・千円・$・R$・€ や「金額・費用・価格・予算」 → amount。「件・人・個・回・kg」 → quantity。どちらもない年度の列 → unknown（v1.4） |
| 率か金額・数量か | %、または値がすべて 0〜1 で列名が「率・割合・ratio」 → rate。指数（2015=100） → unknown |
| 国名・国コード・通貨 | 国名・国コード → address。通貨コード（JPY・BRL・USD） → category |
