# 教材の追加ルール

ここには公開利用条件を確認した教材の記録と、明示された草案演習だけを置く。各素材に出典URL、ライセンス/利用条件、確認日、対象列タイプ、加工手順、プライバシー状態、訓練/検証用途を記録する。

未見試験、blind_set*、セット3・5・7、顧客データ、個人の連絡先は置かない。評価例を教材へ逆流させない。AI生成例は生成元・仮ラベル・人手確認状況を明記し、未確認ラベルを正解データに混ぜない。

## 現在の教材パック
- [優先教材・収集計画](learning-materials-priority-pack-2026-10-18.md): Jitsuris向けの教材設計、短い根拠タグの方針、合成対照例、外部資料のライセンス/安全性調査。
- このパックは調査記録と未確認の合成演習草案であり、訓練用データセットではない。
- 公開コーパスのrawデータ、検証済みの新規訓練例、APIから取得したe-Statデータはまだ追加していない。CPU候補学習も未開始。
- 外部教材を取り込む前に、出典ごとの規約・第三者権利・個人情報・既存データとの重複を確認する。e-Stat API取得には登録/app IDが必要なので、具体表を選んでから取得可否を確認する。

許可条件が確認できないデータは取り込まず、参考資料としてのみ記録する。
