# CPUラボ結果・原因分析

各実験IDごとに候補を報告する。5つの許可済み固定試験について、正解率、誤り数、重大誤り数、不明数、時間、ピークCPUメモリを記録し、同一条件の比較先・seedばらつきと併記する。差が1.5ポイント未満なら差なしとする。

誤りは可能な限り全件調べ、ラベル、分布・重複、列名/値/単位/兄弟列、前処理・トークナイザ、確信度/guard、ハイパーパラメータ、コード/評価不具合を確認する。各所見は事実・仮説・根拠・確度・次の確認に分ける。未確認を断定しない。

CPUラボの結果は候補評価であり、既定モデルへの採用や配布は別途判断する。blind_set*、セット3・5・7には触れない。
